# Календарь звонков

Предметная область сервиса для планирования и бронирования встреч между владельцем и гостями.

## Language

### Роли

**Владелец**:
Человек, предоставляющий своё время для встреч с гостями.
_Avoid_: Пользователь, администратор

**Гость**:
Человек, который бронирует время владельца для встречи. Не является аккаунтом.
_Avoid_: Пользователь, клиент

### Бронирование

**Тип встречи**:
Шаблон встречи с описанием и длительностью, по которому гость бронирует конкретное время. У типа есть автоматический уникальный идентификатор для адресной ссылки, не зависящий от названия.
_Avoid_: Событие, услуга

**Встреча**:
Запланированное взаимодействие владельца с конкретным гостем, занимающее определённый интервал времени. Гость на встрече обозначен именем и почтой.
_Avoid_: Звонок, событие

**Бронирование**:
Действие гостя, в результате которого для выбранного слота создаётся встреча.
_Avoid_: Регистрация, резервирование, запись

### Время и доступность

**Окно записи**:
Четырнадцать календарных дат владельца, начиная с сегодняшней, внутри которых гостю можно предлагать слот. Слот входит в окно по дате старта, а не по дате конца.
_Avoid_: Расписание владельца, доступность, скользящие сутки

**Расписание владельца**:
Правила, определяющие, когда владелец принимает встречи, без учёта уже забронированных встреч.
_Avoid_: Доступность, календарь, окно записи

**Слот**:
Предлагаемый гостю интервал с конкретным началом и длительностью выбранного типа встречи. Шаг возможных начал не определяет длительность слота.
_Avoid_: Время, окно

**Доступность**:
Набор слотов внутри окна записи, которые соответствуют расписанию владельца и не пересекаются с существующими встречами.
_Avoid_: Расписание, свободное время, окно записи
