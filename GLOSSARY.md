# Календарь звонков

Предметная область сервиса для планирования и бронирования встреч между владельцем и гостями.

## Language

### Роли

**Владелец**:
Человек, предоставляющий своё время для встреч с гостями.
_Avoid_: Пользователь, администратор

**Гость**:
Человек, который бронирует время владельца для встречи.
_Avoid_: Пользователь, клиент

### Бронирование

**Тип встречи**:
Шаблон встречи с описанием и длительностью, по которому гость бронирует конкретное время.
_Avoid_: Событие, услуга

**Встреча**:
Запланированное взаимодействие владельца с конкретным гостем, занимающее определённый интервал времени.
_Avoid_: Звонок, событие

**Бронирование**:
Действие гостя, в результате которого для выбранного слота создаётся встреча.
_Avoid_: Регистрация, резервирование

### Время и доступность

**Расписание владельца**:
Правила, определяющие, когда владелец принимает встречи, без учёта уже забронированных встреч.
_Avoid_: Доступность, календарь

**Слот**:
Предлагаемый гостю интервал с конкретным началом и длительностью выбранного типа встречи. Шаг возможных начал не определяет длительность слота.
_Avoid_: Время, окно

**Доступность**:
Набор слотов, которые полностью соответствуют расписанию владельца и не пересекаются с существующими встречами.
_Avoid_: Расписание, свободное время
