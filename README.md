# Календарь звонков

## О проекте

**Календарь звонков** — упрощённый аналог Cal.com для планирования и бронирования встреч.

Владелец создаёт типы встреч с описанием и длительностью, а гости самостоятельно выбирают подходящее время и бронируют встречи. Для обеих ролей регистрация не требуется: функции владельца доступны по заранее определённому URL.

Сервис показывает только время, которое соответствует расписанию владельца и не занято другими встречами.


Учебный проект Хекслета: https://ru.hexlet.io/programs/ai-for-developers  
Как это должно работать: https://files.hexlet.app/a/2ipc5m


## Роли

### Владелец

Владелец управляет календарём и может:

- просматривать список типов встреч;
- создавать типы встреч с описанием и длительностью;
- просматривать встречи, забронированные гостями, включая их тип, дату и время, а также имя и почту гостя.

### Гость

Гость может без регистрации:

- просматривать доступные типы встреч;
- выбирать тип встречи;
- просматривать свободные слоты;
- бронировать встречу, указывая своё имя и почту.

## Правила доступности

- Владелец принимает встречи по будням, с понедельника по пятницу, с 09:00 до 18:00.
- Расписание владельца задано в часовом поясе `Europe/Moscow` (UTC+03:00, без перехода на летнее время).
- Выходные дни недоступны для бронирования.
- Гость видит свободные слоты на ближайшие 14 дней от текущего момента.
- Слоты отображаются в часовом поясе гостя.
- Возможное время начала встречи предлагается с шагом 15 минут: 09:00, 09:15, 09:30 и так далее по времени владельца.
- Встреча должна полностью укладываться в рабочие часы владельца.
- Время, занятое забронированной встречей, недоступно для других встреч. Новая встреча не может пересекаться с уже существующей.


## Основные сценарии

### Создание типа встречи

1. Владелец открывает список типов встреч.
2. Если нужного типа нет, владелец создаёт его, указывая описание и длительность.
3. Созданный тип становится доступен гостям для бронирования.

### Бронирование встречи

1. Гость открывает список типов встреч и выбирает нужный.
2. Сервис показывает свободные слоты на ближайшие 14 дней с учётом расписания владельца, длительности выбранной встречи и существующих бронирований.
3. Гость выбирает подходящий слот.
4. Гость указывает имя и почту и подтверждает бронирование.
5. Встреча появляется в списке встреч владельца, а занятое время исключается из доступности для других гостей.

### Просмотр забронированных встреч

Владелец открывает список встреч и просматривает их параметры и данные гостей.

В текущей версии поддерживаются только создание и просмотр встреч. Отмена и перенос бронирований не предусмотрены.
