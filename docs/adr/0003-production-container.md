# Запуск production-контейнера

**Статус:** accepted

## Решение

Проверка запускает один контейнер из корневого `Dockerfile`. Образ собирает frontend и backend на Node `24.22.3` и pnpm `12.17.0` и стартует сам: `CMD ["node", "dist/server.js"]`. `dist/` копируется явно, потому что каталог в `.gitignore`.

Процесс слушает `0.0.0.0` и порт из `PORT`. Если переменной нет, порт `3000`. Локальный `pnpm dev` остаётся двумя процессами.

В контейнере Express отдаёт собранный frontend только при заданном `STATIC_DIR` и только после маршрутов `/api`. Неизвестный адрес страницы отдаёт `index.html`, запросы `/api` туда не переписываются. В production-сборке нет прокси Vite.

Образ явно копирует `generated/` и `drizzle/`: контракт OpenAPI и миграции не попадают в `dist` при компиляции TypeScript. Данные PGLite пишутся в `DATA_DIR`, по умолчанию `data` относительно рабочей директории (`/app/data` в контейнере). Образ не объявляет том, поэтому без внешней монтировки данные не переживают замену контейнера.

Render MCP описан в `opencode.jsonc`. Ключ в репозиторий не входит: заголовок берёт `{env:RENDER_API_KEY}`.
