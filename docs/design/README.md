# Скетчи интерфейса

Визуальный эталон экранов. Правила продукта остаются в корневом `README.md`. Если скетч и этот файл расходятся, поведение берите из `README.md`, а вёрстку — из PNG.

Открывайте PNG того экрана, который меняете.

1. `landing.png` — главная. Навигация: Calendar, Записаться, Предстоящие события. Заголовок и кнопка Записаться. Боковая карточка «Что доступно прямо сейчас».
2. `meeting_create.png` — запись, выбор слота. «Запись на звонок»: панель сведений, календарь месяца со счётчиком свободных слотов, список слотов, Назад / Продолжить.
3. `meeting_approve.png` — подтверждение. Та же панель сведений; имя и email, Изменить, Подтвердить запись.
4. `meeting_approve_done.png` — бронь подтверждена. «Бронь подтверждена. До встречи!» и Забронировать еще.
5. `schedule.png` — предстоящие события. «Предстоящие события»: имя, email, слот, дата создания.
