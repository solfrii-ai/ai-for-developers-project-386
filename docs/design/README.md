# Скетчи интерфейса

Визуальный эталон экранов. Вёрстку берите из PNG, поведение — из корневого `README.md` и `GLOSSARY.md`. Подписи на скетчах не копируйте: там устаревшие Calendar, «Записаться», «события» и «запись». Субботние слоты и общая 30-минутная сетка на рисунках — контекст макета, не правило расписания.

Открывайте PNG того экрана, который меняете.

1. `landing.png` — главная: шапка, герой и боковая карточка «Что доступно прямо сейчас».
2. `meeting_create.png` — выбор слота: панель сведений, календарь месяца со счётчиком свободных слотов, список слотов, Назад / Продолжить.
3. `meeting_approve.png` — подтверждение: та же панель, имя и почта.
4. `meeting_approve_done.png` — бронирование подтверждено.
5. `schedule.png` — предстоящие встречи: тип, гость, интервал и дата создания.
