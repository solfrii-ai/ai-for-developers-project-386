# Настройка OpenCode для работы по комментариям

## Ключевые ограничения

- До согласования — только исследование и проверки без изменений.
- Значения секретов не читать и не выводить; ключ в чате не запрашивать.
- Сначала показать план, состояние доступов и необходимые действия владельца.
- Исключения для диагностики — только после отдельного решения пользователя.
- После согласования — настроить, проверить, закоммитить, доставить в `main` и провести реальный запуск.
